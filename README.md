# Простой TCP клиент-сервер на Python

Этот проект демонстрирует базовое сетевое взаимодействие между клиентом и сервером с использованием TCP-сокетов в Python.

## Описание

Проект состоит из двух частей:
- **TCP-сервер**: Принимает подключения от клиентов, получает данные и отправляет их обратно (эхо-сервер)
- **TCP-клиент**: Подключается к серверу, отправляет сообщение и получает ответ

HOST = "127.0.0.1" (localhost)
HOST = "192.168.56.1" (локальная сеть)
